Leaderboard

      

        
Skill rescales each benchmark's own metric so that 0 is the trivial baseline and 1 is the metric ceiling. Position rescales it so that 1 is the strongest published specialist. The three Gemini models ran through a text-only client and have no result on the  image benchmarks, so the common set compares all  models on the same  text benchmarks.

Evidence and controls


      
Removing the record

      

        
Three models answered each benchmark again with the record deleted from the prompt. Of  model and benchmark pairs with a paired 95% interval,  scored lower without the record and  scored higher.

      

      

      


      
Channel and representation ablations

      

        
Deleting or rewriting one part of the record shows which part a model reads. The full record gains over the ablated one, with a paired 95% interval that excludes zero, in  of  comparisons. 

      

      


      
After the training cutoff

      

        
Two tests use data measured or deposited after every model's training cutoff, so no answer can have been seen in training.

Memory checks

Same units as the specialist

      

        
On  benchmarks the specialist's own predictions were scored on the same sampled units as the language models. Each cell is the model's score minus the specialist's, signed so that a positive value favours the model.

Methods and downloads

      

        

          
Every run starts in an empty directory with no tools, through each developer's own command-line client. A benchmark keeps its units, question and scorer. Each model answers a sample of  to  test units per benchmark, and intervals are 95%. Paired comparisons score the same units under both conditions.

          
Benchmark specifications, native scorers, evaluation harness, and every data table behind this page are open source on GitHub (albert-ying/RawSci-Bench).
