# Ying Lab website

Static site for lab.kejunying.com. No build step: the repository root is the published folder.

- `index.html`, `styles.css`: page and styles
- `main.js`: lifespan axis, research loop, lists, navigation
- `film.js`: hero particle scene, eased scrolling, line and rule animations
- `data.js`: "Work so far" entries and selected publications; edit content here
- `assets/`: fonts (Oxygen, Instrument Serif, JetBrains Mono, all SIL OFL), artwork, icons

Preview locally with `python3 -m http.server 4173`.
